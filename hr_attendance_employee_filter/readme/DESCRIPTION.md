This module enhances the Attendance list view by adding a predefined
Employee filter to the existing search interface.

HR managers can quickly narrow the Attendance list down to a single
employee, searching by name, without having to open the "Add Custom
Filter" dialog. The filter reuses the existing `employee_id` field on
the attendance record and can be freely combined with the existing
date and attendance filters (e.g. "At Work", "Missing Check-Out").
