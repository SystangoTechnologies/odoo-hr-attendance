1.  Go to *Attendances \> Attendances*.
2.  In the search panel on the left of the list, pick the *Employee*
    you want to review under the *Employee* category, or type the
    employee's name directly in the search bar.
3.  Only the attendance records of the selected employee are shown.
    The filter can still be combined with the existing *Date* and
    *At Work* / *Missing Check-Out* filters.
4.  Click the employee again (or *See all*) to remove the filter and
    go back to the full Attendance list.
