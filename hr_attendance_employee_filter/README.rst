This module enhances the Attendance list view by adding a predefined
Employee filter to the existing search interface.

HR managers can quickly narrow the Attendance list down to a single
employee, searching by name, without having to open the "Add Custom
Filter" dialog. The filter reuses the existing ``employee_id`` field on
the attendance record and can be freely combined with the existing date
and attendance filters (e.g. "At Work", "Missing Check-Out").

Usage
=====

1. Go to *Attendances > Attendances*.
2. In the search panel on the left of the list, pick the *Employee* you
   want to review under the *Employee* category, or type the employee's
   name directly in the search bar.
3. Only the attendance records of the selected employee are shown. The
   filter can still be combined with the existing *Date* and *At Work* /
   *Missing Check-Out* filters.
4. Click the employee again (or *See all*) to remove the filter and go
   back to the full Attendance list.
