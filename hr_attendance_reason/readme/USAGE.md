1.  Go to *Attendances \> Configuration*.
2.  Create the reasons that may cause attendances to be shorter or
    longer than normal
3.  When that situation occurs employees can justify the reason

## Required Reason Enforcement

When the "Show reasons on attendance screen" setting is enabled for a company, you can optionally enforce that employees must provide a reason when checking out. To enable this:

1.  Go to *Settings \> Attendance \> Attendance Reasons*.
2.  Check "Show reasons on attendance screen".
3.  Check "Required reason on attendance screen".

With this enabled, employees attempting to check out via the kiosk without selecting a reason will see an error message and the check-out will not be saved.

## Default Reason Behavior

When "Show reasons on attendance screen" is enabled but "Required reason on attendance screen" is disabled, you can configure default reasons that will be automatically applied when employees do not select one:

1.  Go to *Settings \> Attendance \> Attendance Reasons*.
2.  Ensure "Show reasons on attendance screen" is checked.
3.  Leave "Required reason on attendance screen" unchecked.
4.  Select a "Default sign-in reason for attendance screen" for automatic sign-in reasons.
5.  Select a "Default sign-out reason for attendance screen" for automatic sign-out reasons.

Employees can still select a different reason, but if they don't, the configured default will be applied automatically.

## Multi-Company Support

All attendance reason settings are per-company. In a multi-company environment, each company can have its own:

*   Attendance reasons
*   Reason enforcement settings
*   Default reasons

Settings are applied based on the employee's company, ensuring proper isolation between companies.
